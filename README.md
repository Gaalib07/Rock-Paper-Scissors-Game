# ✊ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and keep track of your score in real time.

## 🎮 Features

- Interactive Rock, Paper, and Scissors buttons
- Play against a computer opponent
- Random computer choice generation
- Automatic winner detection
- Real-time player and computer score tracking
- Draw detection
- Dynamic result messages
- Clean and user-friendly interface
- Hover effects and responsive layout styling

## 🛠️ Technologies Used

- **HTML5** – Structures the game interface
- **CSS3** – Styles the game layout, buttons, scoreboard, and hover effects
- **JavaScript** – Handles game logic, random choices, winner detection, and score updates

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser. No additional libraries, frameworks, or package installations are required.

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the HTTPS URL of your GitHub repository.

**2. Navigate to the project directory**

```bash
cd Rock-Paper-Scissors-Game
```

**3. Run the game**

Open `index.html` in your web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

## 🕹️ How to Play

1. Open the game in your browser.
2. Choose one of the three options: Rock ✊, Paper ✋, or Scissors ✌️.
3. The computer randomly selects its move.
4. The game determines the winner and displays the result.
5. Your score or the computer's score increases when either side wins.
6. If both choose the same option, the round ends in a draw and neither score increases.

### Game Rules

| Player Choice | Beats |
|---|---|
| ✊ Rock | ✌️ Scissors |
| ✋ Paper | ✊ Rock |
| ✌️ Scissors | ✋ Paper |
